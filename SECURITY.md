# Security

Report security issues through this fork's [security page](https://github.com/pattaraprach/pstack/security). If private reporting is unavailable, contact the repository owner without publishing exploit details or credentials.

The Codex overlay, generator, validation tools, and update workflow are maintained in this fork. Report problems in unchanged original skills to [cursor/plugins](https://github.com/cursor/plugins/security). Report Codex loader defects to OpenAI.
